Privacy Policy

Last updated: August 29, 2026

Introduction

FitCoach (also called Gym Sync) is a local-first desktop dashboard that combines Jefit workout exports with WHOOP recovery, sleep, and strain data to generate personal training insights on your own computer.

Your privacy matters. This policy explains what FitCoach does and does not do with your information when you use the app, including the optional WHOOP API connection.

Local-first design

FitCoach runs on your machine. Workout history, WHOOP metrics, coaching insights, and configuration are stored locally (for example in a SQLite database and local config files). We do not operate a FitCoach cloud account that stores your training data.

  • Jefit CSV/zip imports and WHOOP zip exports stay on your device unless you choose to share files yourself.
  • Dashboard and CLI tools read and write local project files only.
  • FitCoach does not sell, rent, or use your training data for advertising.

WHOOP integration

If you connect WHOOP through the official WHOOP Developer API (OAuth), FitCoach requests read-only access to recovery, cycles, sleep, and workout data, plus the offline scope so tokens can be refreshed without signing in every time.

  • OAuth client credentials and tokens are stored only on your device (for example under a local data/ folder or environment variables).
  • FitCoach uses those tokens solely to fetch your WHOOP data into the local database for coaching insights.
  • FitCoach does not post workouts, change your WHOOP account, or share your WHOOP data with third parties.
  • WHOOP’s own handling of your account and API data is governed by WHOOP’s privacy policy.

Jefit data

Jefit does not provide an official OAuth API for this app. FitCoach imports data you export (CSV) or, if you explicitly enable a public scrape, reads publicly visible profile/log pages according to your Jefit privacy settings. FitCoach does not upload your Jefit exports to our servers.

OAuth redirect page

The GitHub Pages page whoop-callback.html exists so WHOOP can redirect your browser after you authorize FitCoach. That page only reads the temporary authorization code and state from the URL so it can hand them to your local FitCoach dashboard (or show them for a one-time CLI paste). It does not store those values on a FitCoach server.

Third parties

FitCoach does not embed advertising or analytics SDKs. When you use the WHOOP API connection, your browser and app communicate with WHOOP’s services. Hosting of this privacy policy and the OAuth helper page is on GitHub Pages (GitHub’s service).
